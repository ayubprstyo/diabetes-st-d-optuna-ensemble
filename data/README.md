# Data

This repository does not redistribute the dataset. Obtain it from either source:

1. **Kaggle** – A. Teboul, *Diabetes Health Indicators Dataset*:
   https://www.kaggle.com/datasets/alexteboul/diabetes-health-indicators-dataset
   Download `diabetes_binary_health_indicators_BRFSS2015.csv` and place it in this folder.
   Or, in Python: `kagglehub.dataset_download("alexteboul/diabetes-health-indicators-dataset")`.
2. **Original source** – U.S. Centers for Disease Control and Prevention, BRFSS 2015 survey data:
   https://www.cdc.gov/brfss/annual_data/annual_2015.html

Expected file: 253 680 rows × 22 columns (target `Diabetes_binary` and 21 features), no missing values, 24 206 duplicate rows.
